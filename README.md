## 📖 Overview

A comprehensive **Exploratory Data Analysis (EDA)** project focused on wine quality data. Demonstrates best practices for data exploration — from initial data profiling to advanced statistical analysis and visualization.

---

## 🎯 EDA Workflow

1. Data Loading and Overview — Shape, dtypes, head/tail, info
2. Missing Value Analysis — Heatmaps, percentage missing, imputation strategies
3. Univariate Analysis — Histograms, box plots, KDE plots for each feature
4. Bivariate Analysis — Scatter plots, correlation heatmaps, pair plots
5. Outlier Detection — IQR method, Z-score, box plot visualization
6. Feature Correlation — Pearson/Spearman correlation matrices

---

## 📊 Dataset

| Property | Details |
|----------|---------|
| **Source** | UCI Machine Learning Repository |
| **Samples** | 6,497 (red + white wine) |
| **Features** | 11 physicochemical properties |
| **Target** | Quality score (0–10) |
